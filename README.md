# 国庆节 C++ 终端爱心特效

这是一个使用 C++ 编写的纯终端控制台程序。运行后，用户可以通过键盘输入自定义尺寸和 RGB 渐变色，程序会在终端中逐行动画打印出由“国庆节快乐”字符组成的大爱心。

## 📥 直接体验（普通用户）

如果你只是想看效果，无需配置开发环境：
1. 点击本仓库右侧的 **[Releases]** 标签页。
2. 下载最新版本的 `.exe` 文件。
3. 双击运行（推荐在 **Windows Terminal** 或 Win10/11 自带控制台中运行，以获得最佳真彩色效果）。

## ✨ 功能特性

- **高度自定义**：用户可以自定义终端的宽（Width）、高（Height）。
- **24 位真彩色渐变**：自定义起始颜色和结束颜色，程序自动计算并插值生成平滑的渐变效果。
- **逐行动画效果**：爱心每一行打印后会有 150ms 的延迟，形成“像在画心”的动态视觉。
- **精准填字排版**：根据爱心内部的空间，自动循环填充“国庆节快乐”，遇到行末空间不足 6 个字符时，自动用 `!` 补齐。

## 🛠️ 源码构建（开发者）

### 环境要求
- **操作系统**：Windows 10 / 11
- **编译器**：支持 C++17 或更高版本的 MSVC (Visual Studio 2019/2022)
- **无第三方依赖**：使用纯 Windows API 和 C++ 标准库，**无需安装 EasyX**。

### 编译指令 (MSVC)
打开 *Developer Command Prompt for VS*，进入源码目录执行：
```bash
cl /EHsc /std:c++17 /utf-8 national_day.cpp
运行编译出的程序：
